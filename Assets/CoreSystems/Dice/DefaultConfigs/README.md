# Default Dice Configurations

This folder contains default/pre-configured DiceConfig ScriptableObjects that can be used as starting points or templates.

## Included Configs

### StandardDice
A standard 2d6 configuration (2 dice, 6 sides each) - commonly used in board games like Catan.

## Usage

1. **Copy and Modify**: Copy a config and modify it for your needs
2. **Direct Use**: Use the config directly in your game
3. **Template**: Use as a template to create new configs

## Creating Your Own Defaults

Feel free to add more default configs here:
- D20Dice (for D&D style games)
- CustomDice (with custom face values)
- WeightedDice (with weighted probabilities)

These configs serve as examples and starting points for your game-specific dice configurations.
